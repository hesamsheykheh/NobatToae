# 📱 Mini App نوبت‌دهی تلگرام (چند کسب‌وکاره)

این نسخه دیگه ربات دکمه‌ای قدیمی نیست. همه‌چیز — رزرو، پنل مدیریت، ساخت کسب‌وکار — داخل یک **Mini App واقعی** (صفحه وب داخل تلگرام) انجام می‌شه. ربات تلگرام فقط دو وظیفه داره: باز کردن Mini App، و ارسال نوتیفیکیشن (یادآوری/درخواست نظر) — چون پوش‌نوتیفیکیشن فقط از طریق خود ربات ممکنه.

## 🗂 ساختار فایل‌ها
```
├── bot.py          # ربات حداقلی: فقط /start (باز کردن اپ)، /claimadmin، و دریافت امتیاز/نظر
├── jobs.py         # جاب‌های پس‌زمینه: یادآوری نوبت، تکمیل خودکار، درخواست نظر
├── database.py     # لایه دیتابیس SQLite (مشترک بین ربات و Mini App)
├── webapp_api.py   # بک‌اند FastAPI - تمام منطق رزرو و مدیریت از اینجا سرو می‌شه
├── webapp/index.html  # فرانت‌اند Mini App (مشتری + پنل مدیریت + ساخت کسب‌وکار)
├── run_all.py      # اجرای هم‌زمان ربات + سرور وب
├── config.py, requirements.txt, .env.example
```

## ✅ همه‌چیز کجاست؟

| امکان | کجا پیاده شده |
|---|---|
| رزرو نوبت (خدمت→متخصص→تاریخ→ساعت→تایید) | Mini App |
| ساخت کسب‌وکار جدید توسط هرکسی | Mini App (دکمه «➕ کسب‌وکار من») |
| پنل مدیریت کامل (داشبورد، خدمات، متخصص‌ها، برنامه کاری، تعطیلات، تخفیف، نظرات، درآمد، CSV، ادمین‌ها، بازخورد) | Mini App |
| امتیاز وفاداری و کد تخفیف در لحظه رزرو | Mini App + بک‌اند |
| یادآوری ۲۴ ساعته / ۱ ساعته قبل از نوبت | پیام ربات (push) |
| درخواست امتیازدهی بعد از نوبت | پیام ربات با دکمه‌های ⭐ (push) |
| دعوت ادمین دوم | ساخت کد از Mini App، پذیرش با `/claimadmin` در ربات |

## 🚀 نصب و اجرا

```bash
pip install -r requirements.txt
python run_all.py
```
این دستور هم ربات (polling) و هم سرور Mini App (روی پورت ۸۰۸۰ یا متغیر `PORT`) رو با هم اجرا می‌کنه.

### مراحل راه‌اندازی کامل
1. از [@BotFather](https://t.me/BotFather) یک ربات بسازید و توکن + یوزرنیمش رو بگیرید
2. در `config.py` مقدار `BOT_TOKEN` و `BOT_USERNAME` رو ست کنید
3. `python run_all.py` رو اجرا کنید (روی Replit: دکمه Run) تا سرور بالا بیاد و یه آدرس HTTPS عمومی بگیرید
4. اون آدرس رو در `config.py` به‌عنوان `MINI_APP_URL` ست کنید (**باید HTTPS باشه**)
5. ربات رو دوباره اجرا کنید
6. در BotFather با `/mybots` → ربات‌تون → `Bot Settings` → `Menu Button`، آدرس Mini App رو به‌عنوان دکمه منوی ربات هم ست کنید (اختیاری ولی توصیه‌شده، تا کاربر همیشه دسترسی سریع داشته باشه)
7. به ربات پیام `/start` بدید — دکمه «🌐 باز کردن اپ» میاد؛ بزنیدش و از همون‌جا «➕ کسب‌وکار من» رو بزنید تا اولین کسب‌وکارتون ساخته بشه

## 🔐 امنیت

- هر درخواست به بک‌اند هدر `X-Telegram-Init-Data` رو می‌فرسته؛ بک‌اند اون رو با `BOT_TOKEN` و الگوریتم رسمی تلگرام (HMAC-SHA256) اعتبارسنجی می‌کنه — آیدی کاربر قابل جعل نیست
- هر endpoint ادمین، جدا از initData، چک می‌کنه کاربر واقعاً توی جدول `business_admins` همون کسب‌وکار هست یا نه؛ در غیر این‌صورت خطای ۴۰۳ می‌گیره
- پارامترهای URL (مثل `?biz=`) فقط برای مشخص کردن «کدوم کسب‌وکار» هستن، نه احراز هویت

## 🧪 وضعیت تست
- تمام فایل‌های پایتون و جاوااسکریپت از نظر سینتکسی بررسی و تاییدشده
- منطق دیتابیس (رزرو، تخفیف، امتیاز وفاداری، برنامه کاری، تعطیلات) قبلاً جداگانه با اسکریپت تست واقعی اجرا و تایید شده
- چون این محیط ساخت به اینترنت دسترسی نداره، نصب واقعی FastAPI/uvicorn و تست end-to-end واقعی داخل تلگرام انجام نشده — بعد از اجرای واقعی، هر خطایی دیدید بگید تا رفعش کنم
